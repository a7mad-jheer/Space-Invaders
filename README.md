# Space Invaders

A fully functional Space Invaders arcade game built from scratch 
using Vanilla JavaScript and HTML5 Canvas — no frameworks, no libraries.

## Live Demo
👉 [Play Now](https://a7mad-jheer.github.io/Space-Invaders/)

## Built With
- Vanilla JavaScript (ES6+)
- HTML5 Canvas API
- CSS3

## Features
- Real-time collision detection
- Enemy movement patterns
- Core game loop & rendering engine
- Score tracking system
- Keyboard controls

## Run Locally
git clone https://github.com/a7mad-jheer/Space-Invaders.git
cd Space-Invaders
# Open index.html in your browser

##  What I Learned 
- Browser Canvas API & 2D rendering
- Game loop architecture
- JavaScript fundamentals without any framework
